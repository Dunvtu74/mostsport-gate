# Mostsport gate

Телефоны ходят на мост `https://185.17.3.167` и не качают новый APK.

Чтобы сменить сайт для всех сразу, отредактируйте `config.json` и сохраните файл в ветку `main`.
Сервер подхватывает файл примерно за минуту.

- `site` — домен, на который мост пересылает приложение
- `mirrors` — запасные домены, если текущий недоступен

Ключей и паролей в этом репозитории нет.
